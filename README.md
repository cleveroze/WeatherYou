# WeatherYou · Погода

Погода для Android в стиле **Material 3 Expressive** — Kotlin + Jetpack Compose,
настоящие компоненты Google: `MaterialShapes` (печеньки, клеверы, солнца-звёзды),
`LoadingIndicator` с морфингом фигур, `MotionScheme.expressive()` с пружинной физикой.

## Что умеет

- **Определяет, где вы**: GPS/сеть, а без разрешения — примерно по IP. Город — через системный геокодер.
- **Живое небо**: цвет фона зависит от погоды и времени суток, дождь, снег, звёзды, вспышки молний,
  плавающие печеньки и клеверы Material.
- **Огромная температура внутри фигуры M3**, которая морфится при смене погоды
  (солнце → печенька → клевер → цветок) и медленно вращается; счётчик температуры на пружине.
- Почасовой прогноз с кривой температуры, прогноз на 10 дней с цветными диапазонами
  (тап — подробности дня).
- Карточки: ветер (компас на 12-гранной печеньке), влажность (вода в клевере с волной), УФ, давление,
  солнце (дуга восхода/заката), ощущается, видимость, осадки, облачность, качество воздуха.
- Экспрессивная загрузка: `LoadingIndicator`, шиммер-скелетоны, staggered-появление, pull-to-refresh.
- Поиск и сохранение городов, офлайн-кэш.
- Настройки: цвет (обои Material You или пресеты, по умолчанию — древесный), тема, °C/°F, м/с / км/ч,
  мм рт. ст. / гПа, анимации.

## Данные

[Open-Meteo](https://open-meteo.com/) (прогноз, качество воздуха, поиск городов) — бесплатно и без ключей.
IP-геолокация: ipwho.is, запасной — geojs.io.

## Сборка

GitHub Actions собирает APK на каждый пуш и публикует его в **Releases**.
Локально: `./gradlew assembleRelease`.

Чтобы обновления ставились поверх старой версии, добавьте секреты
`WEATHERYOU_KEYSTORE_BASE64`, `WEATHERYOU_KEYSTORE_PASSWORD`, `WEATHERYOU_KEY_ALIAS`, `WEATHERYOU_KEY_PASSWORD`.
