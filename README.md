# WeatherYou

Минималистичная погода для Android в стиле **Material 3 Expressive**.
Kotlin, Jetpack Compose, динамический цвет Material You, Open-Meteo без API-ключей.

## Что внутри

- Динамическая палитра Material You (Android 12+) с мягким фолбэком.
- Погодный фон, который подмешивает настроение погоды к цветам системы.
- Анимированная сцена: солнце с лучами, луна и звёзды, плывущие облака, дождь, снег, гроза.
- Огромная температура с пружинной анимацией, почасовой прогноз, детали, неделя с диапазонами температур.
- Поиск города через Open-Meteo Geocoding, кэш последнего прогноза для офлайна.
- Pull-to-refresh, edge-to-edge, предиктивный back, один экран без лишнего.

## Данные

[Open-Meteo](https://open-meteo.com/) — бесплатно, без ключа.
Город по умолчанию — Новосибирск, меняется в приложении.

## Сборка

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions собирает APK на каждый пуш в `main` и кладёт его в релиз **latest** и в артефакты workflow.
